# 清单对比与校审工具（ChecklistTool）

> 完整项目说明见仓库根 [README.md](../README.md)；本文件为目录内简版，侧重运行与打包。

离线桌面版：同一清单不同版本对比、基于自定义规则的校验、多清单交叉对比；支持 Excel、CSV、TSV、Word 等格式；结果可导出 PDF/Excel/CSV，带差异高亮与规则违规标记。

## 功能概览

- **版本对比**：两版清单按键列匹配，识别新增/删除/修改行，可配置对比列。
- **规则校验**：按规则库中的条件树校验数据，高亮违规字段并提示规则名称。
- **数据生成**：根据规则库中的规则生成合规数据行（固定行数随机生成或按规则分支全覆盖），可选用模板文件提供列结构与示例值。
- **设备数据**：内嵌 SQLite 数据库，在工具内直接填写设备清单；编辑单元格时按所选规则即时审查（违规单元格红色高亮+悬浮提示规则名），支持全表校验、违规明细跳转、Excel 导入/导出。
- **交叉对比**：基准清单与多个待对比清单逐表对比。
- **规则库**：默认只读；需要输入秘钥解锁后才可新增/编辑/删除规则（可视化条件树）。
- **结果报告**：表格预览，导出 PDF（带格式）、Excel（含标记与高亮）、CSV（纯数据）。

## 环境与运行

```bash
# Python >= 3.11（锁定版本中的 pandas 3.x 要求）
pip install -r requirements.txt
python main.py
```

规则库默认只读；点击“解锁编辑（需秘钥）”后可修改规则。秘钥建议通过环境变量 `CHECKLISTTOOL_RULES_EDIT_KEY` 配置。规则库保存在 `user_data/rules/`，导出与日志在 `user_data/exports/`、`user_data/logs/`。

## 打包与部署（Windows）

打包由 [ChecklistTool.spec](ChecklistTool.spec) 定义，一次构建同时产出两种分发形态：

| 产物 | 路径 | 说明 |
|------|------|------|
| 免安装文件夹（推荐） | `dist\ChecklistTool\` | 启动快；整个文件夹随共享盘/压缩包分发 |
| 免安装 zip | `dist\ChecklistTool_v2.2_免安装.zip` | 免安装文件夹的压缩包，解压即用 |
| 单文件 exe | `dist\ChecklistTool.exe` | 单文件分发方便，但每次启动需自解压（首次 20~60 秒） |

构建（首次需联网安装依赖）：

```powershell
powershell -ExecutionPolicy Bypass -File .\build_exe.ps1
```

脚本流程：创建虚拟环境 → 安装锁定依赖 → 开发态冒烟 → PyInstaller 构建 → 对两个冻结 exe 自动执行 `--smoke-test`（导入全部重型库 + 读写回环验证）→ 清理测试数据 → 压缩免安装包。构建机需 Python ≥ 3.11（PyInstaller ≥ 6.16 支持 Python 3.14）。

部署注意：

- **放在可写目录**（桌面、D 盘工具目录、共享盘）：运行数据 `user_data\` 生成在 exe 旁；若所在目录只读，规则库自动回退到 `%USERPROFILE%\清单对比校审工具\rules`。
- **杀软误报**：单文件 exe 较易被 Windows Defender 误报，内部分发建议优先使用免安装文件夹；如误报可对 `dist\` 添加排除或对 exe 做代码签名。
- **诊断旗标**：`ChecklistTool.exe --smoke-test` 执行无界面自检，结果写入 `user_data\logs\smoke_test.log`，退出码 0 为通过（正常使用无需该参数）。
- **PDF 中文渲染**：导出 PDF 时自动注册 Windows 自带黑体（simhei/msyh/simsun 依次尝试）渲染中文；目标机器为简体中文 Windows 即无需任何配置。
- 图标与版本信息：exe 属性（右键 → 详细信息）显示“清单对比与校审工具 v2.2.0.0”；图标可通过 `python tools\make_icon.py` 重新生成（需 `requirements-build.txt`）。

## 设备数据（内嵌数据库）

数据保存在 `user_data\checklist_db.sqlite`（SQLite，WAL 模式），随程序目录走；界面为"设备数据"页：

- **清单管理**：新建（手动列名 / 全局模板列 / 从 Excel 导入列结构或列+数据）、复制、重命名、删除；列可右键表头插入/重命名/删除。
- **自动保存**：编辑后约 0.3 秒自动写入数据库，无需手动保存；支持 Ctrl+C/Ctrl+V 批量复制粘贴、Del 删除行、底部新增行。
- **即时审查**：编辑行按"审查规则"下拉（全部规则或某规则集）即时校验，违规单元格红色高亮、悬浮显示规则名；"全表校验"生成完整违规明细（点击跳转行），导出时违规单元格带高亮。
- **全局模板列**：管理员秘钥解锁后在"全局模板列"中维护，新建清单可一键复用，保证字段规范。

限制说明：

- 数据为**本机单用户**使用；同一时间请勿用多个程序实例同时打开同一清单（SQLite 会排队写入，界面不实时同步）。
- 审查所用规则库仍为各客户端本地 JSON（与规则校验页一致）。
- 当前版本行按填写顺序排列，不支持排序/筛选；大清单采用分页加载（每页 2000 行）。

## 表头说明

支持多级表头（如 Excel 中多行表头）：解析器会自动检测或按配置表头行数，将多行合并为层级列名（如 `系统|专业`），便于在键列与对比列中选择。

## 扩展建议

- 支持 `.et` 格式：可接入 WPS 转换或专用库。
- 规则库可改为 SQLite，支持更多元数据。
- 导出样式（颜色、字体）可通过配置或主题扩展。
